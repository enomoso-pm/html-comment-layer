# examples — 記事のデモ

Qiita記事「HTML資料にFigma風コメントを後付けして、レビュー指摘をそのままAIへの修正指示にする」で
使っているデモの実物です。架空のPOS刷新提案資料「Project NOVA」を、提出前の社内レビューという
設定で3人がレビューした状態（指摘9件・返信3件・完了1件）が入っています。

`demo-次世代POSシステム刷新プロジェクト_commented_2608080631.html` をブラウザで開いて、

1. 本文のハイライトとサイドバーのカードを押して、指摘と本文の往復を体感する
2. 「AIに渡す指摘をコピー」で、AIへの修正指示がどう出るかを見る
3. 自分の名前を足してコメントを書き、「資料を保存」まで一巡する

コマンドを再現したければ、リポジトリ直下で:

```bash
python3 scripts/add_comment_layer.py examples/demo-次世代POSシステム刷新プロジェクト_commented_2608080631.html --check
```

資料の中身（社名・数値・人名）はすべて架空です。
