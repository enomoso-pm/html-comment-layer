      この資料へのコメントのしかた
      この資料は、そのまま書き込めます

      アプリのインストールもログインも要りません。気づいたことをその場に書き込んで、 最後にファイルを1つ書き出して返すだけです。書き込んだ内容はこのHTMLファイルの中に入ります。

      • 本文の気になった箇所を選んでコメントする
      • 図やレイアウトにはピンを刺してコメントする
      • 右側の一覧で、コメントを読む・直す・完了にする
      画面下のバー（ピンを置く・コメント一覧）と、左下の「使い方」が入口です。閉じたり消えたりしません。
      まず、操作中のユーザーを選ぶ

      サイドバー上部の「操作中のユーザー」が、これから書くコメント・返信につく名前と色です。 書く前に、自分の名前になっているか確かめてください。

      • 欄を押すと登録済みのユーザーが一覧で出ます。人数が多いときは名前を打って絞り込めます
      • ↑← で1つ上、↓→ で1つ下。 Enter で決定、Esc で取り消し。マウスを重ねればそれが優先されます
      • 一覧にない人は、「ユーザーを管理」を押して名前と色を決めて追加します （Enter でも追加できます）
      「ユーザーを管理」では、名前の変更・色の変更・削除もできます。色はすでに使われている色からいちばん離れた色が自動で選ばれるので、見分けがつかなくなりません。色を変えると、その人が過去に書いたハイライトにも即反映されます。
      本文を選ぶ → 「コメントする」

      気になった文をマウスでなぞって選ぶと、すぐ上に「コメントする」が出ます。 押すと右側に入力欄が開くので、書いて ⌘／Ctrl + Enter（または「保存」）。

      • 選んだ文には色が付き、どこへの指摘かが誰にでも分かります
      • 色の付いた箇所をクリックすると、その指摘が一覧で光ります
      • 逆に一覧のカードをクリックすると、本文がその場所まで動きます
      選び直したいときは、もう一度別の場所をなぞるだけ。間違えて保存しても、カード右上の「…」から編集できます。
      図やレイアウトには、ピンを刺す

      「この図の並びが分かりにくい」「ここに余白がほしい」など、 文字ではなく場所そのものへの指摘はピンで示します。

      • 下のバーの「ピンを置く」（または C）を押す
      • 資料の刺したい場所をクリックすると、そこに丸いピンが立つ
      • コメントを書いて保存。ピンはあとからドラッグして動かせます
      ピンをやめたいときは、もう一度「ピンを置く」を押すか Esc。
      片付いた指摘は「完了」にする

      直した指摘、もう見なくていい指摘は、カード右上のチェックを押します。 消えるわけではありません。一覧の一番下、「完了済み」の区切り線の下へ移動するだけです。

      • チェック … 完了にする／完了を取り消す。よく使うのでボタンのまま出しています
      • 「…」（3点リーダー） … 編集・担当者を変更・削除・完了を ここにまとめました。めったに使わない操作で押し間違えないためです
      • 担当者を間違えたときは、書き直さなくて大丈夫。「…」→「担当者を変更」で 別の人に付け替えられます。本文のハイライトの色もその場で変わります。返信も同じように直せます
      • 誰がいつ完了にしたかが、カードに残ります。並び順（最後に書いた時刻）は変わりません
      • 「完了済み ○件」の区切りを押すと、完了した指摘をまとめて畳めます。 件数はそのまま出ているので、消えたのではないことが分かります。もう一度押せば開きます （この設定はあなたの手元にだけ残り、書き出すファイルには入りません）
      完了は「消す」ではなく「片付ける」。何を直したかの記録がそのまま残るので、次の版で同じ指摘が出戻りません。
      返信でやりとり、優先度で重みづけ

      1つの指摘に対して「直しました」「まだ調整中です」を同じカードに積んでいけます。 上書きしないので、経緯がそのまま残ります。

      • 返信 … カードの下から返信を追加。返信が付くとそのカードが一覧の上に上がります
      • 優先度 … 名前の横のチップをクリックするたびに 必須（必ず直す）→ 要望（できれば直す）→ 軽微（細かい好み）→ なし と切り替わります
      優先度は並び替えにも、コピーした文章にも入るので、AIに直させるときに「どれから直すか」が伝わります。
      並び順を変える／キーで見て回る

      一覧の上にあるセレクタで、コメントの並びを切り替えられます。

      • 更新順（初期設定）… 最後に書いた・返信したものが上。いま動いている話を追うとき
      • 優先度順 … 必須 → 要望 → 軽微 → なし の順。重い指摘から片付けるとき
      • 並び順を変えても資料は変わりません。あなたの画面での見え方だけが変わります

      J で次のコメント、K で前のコメントへ。 本文も一緒に動くので、マウスを使わずに端から確認できます。 Shift を一緒に押すと、完了したものを飛ばします。 L で一覧そのものを開いたり閉じたりできます。

      最後に、保存して相手に送る

      書いただけでは、相手には伝わりません。 「資料を保存」を押すと、コメントごと入ったHTMLがあなたのパソコンにダウンロードされ、 画面の上に「保存しました」という案内が出ます。 保存されるのはあなたのパソコンの中だけなので、そのままでは相手には届きません。 いま保存されたそのファイルを、Slackやメールでそのまま送ってください。

      • 資料を保存（⌘／Ctrl + S） … コメントごとHTMLを書き出します。押した直後に画面上部に案内が出るので、見落としません
      • AIに渡す指摘をコピー（⌘／Ctrl + Shift + S） … 全コメントを1つの文章にまとめてクリップボードへ写します。 これをAIに貼って「反映して」と頼めば、資料をそのまま直させられます。Slackに貼って指摘を共有するのにも使えます。 完了した指摘は「対応済み・修正不要」と明記されるので、直した箇所を蒸し返しません
      保存する前にタブを閉じてしまっても大丈夫。同じファイルを開き直すと、「前回の未保存コメントを復元しますか？」と聞いてくれます。
