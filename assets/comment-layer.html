コメントスレッド

※色を変えると既存のピン・ハイライトにも即反映されます。
📖 この資料へのコメントのしかた
この資料は、そのまま書き込めます

アプリのインストールもログインも要りません。気づいたことをその場に書き込んで、 最後にファイルを1つ書き出して返すだけです。書き込んだ内容はこのHTMLファイルの中に入ります。

  • 本文の気になった箇所を選んでコメントする
  • 図やレイアウトにはピンを刺してコメントする
  • 右側の一覧で、コメントを読む・直す・完了にする
画面下のバー（📍ピン・💬コメント一覧）と、左下の「📖 使い方」が入口です。閉じたり消えたりしません。
まず、操作中のユーザーを選ぶ

サイドバー上部の「操作中のユーザー」欄が、これから書くコメント・返信につく名前と色です。 書く前に、自分の名前になっているか確かめてください。

  • 欄を押すとこれまでの参加者が候補に出ます。選んで確定すれば、その人に切り替わります
  • 候補にない名前を打ち込んで確定すると、その場で新しい参加者として追加されます（作り直しは不要）
  • 確定は Enter または ⌘／Ctrl + Enter。 Esc か他の場所を押すと、確定せずに元の名前へ戻ります
レビュアーの色を変えたいときは、欄の右の⚙️から。色を変えると、その人が過去に書いたハイライトにも即反映されます。
本文を選ぶ → 💬 コメントする

気になった文をマウスでなぞって選ぶと、すぐ上に「💬 コメントする」が出ます。 押すと右側に入力欄が開くので、書いて ⌘／Ctrl + Enter（または「保存」）。

  • 選んだ文には色が付き、どこへの指摘かが誰にでも分かります
  • 色の付いた箇所をクリックすると、その指摘が一覧で光ります
  • 逆に一覧のカードをクリックすると、本文がその場所まで動きます
選び直したいときは、もう一度別の場所をなぞるだけ。間違えて保存しても ✏️ で直せます。
図やレイアウトには 📍 ピンを刺す

「この図の並びが分かりにくい」「ここに余白がほしい」など、 文字ではなく場所そのものへの指摘はピンで示します。

  • 下のバーの「📍 ピンを置く」（または C）を押す
  • 資料の刺したい場所をクリックすると、そこに丸いピンが立つ
  • コメントを書いて保存。ピンはあとからドラッグして動かせます
ピンをやめたいときは、もう一度「📍 ピンを置く」を押すか Esc。
片付いた指摘は ✅ で完了にする

直した指摘、もう見なくていい指摘はカードの ✅ を押します。 消えるわけではありません。一覧の一番下、「完了済み」の区切り線の下へ移動するだけです。

  • 誰がいつ完了にしたかが、カードに残ります
  • やっぱり戻したいときは 🔄 でいつでも元の位置へ
  • 完了にしても並び順（最後に書いた時刻）は変わりません
完了は「消す」ではなく「片付ける」。何を直したかの記録がそのまま残るので、 次の版で同じ指摘が出戻りません。
返信でやりとり、ラベルで優先度

1つの指摘に対して「直しました」「まだ調整中です」を同じカードに積んでいけます。 上書きしないので、経緯がそのまま残ります。

  • 💬 返信 … カードの下から返信を追加。返信が付くとそのカードが一覧の上に上がります
  • ラベル … 名前の横のチップをクリックするたびに must（必ず直す）→ want（できれば）→ nit（細かい好み）→ なし と切り替わります
ラベルは「指摘をコピー」の出力にも入るので、AIに直させるときに優先順位が伝わります。
並び順を変える／キーで見て回る

一覧の右上のセレクタで、コメントの並びを切り替えられます。

  • 更新順（初期設定）… 最後に書いた・返信したものが上。いま動いている話を追うとき
  • 文書順 … 資料の上から順。頭から通して読むとき
  • 並び順を変えても資料は変わりません。あなたの画面での見え方だけが変わります

J で次のコメント、K で前のコメントへ。 本文も一緒に動くので、マウスを使わずに端から確認できます。 Shift を一緒に押すと、完了したものを飛ばします。

最後に、保存して相手に送る

書いただけでは、相手には伝わりません。 「保存」を押すと、コメントごと入ったHTMLがあなたのパソコンにダウンロードされます。 保存されるのはあなたのパソコンの中だけなので、そのままでは相手には届きません。 いま保存されたそのファイルを、Slackやメールでそのまま送ってください。

  • 💾 資料を保存（⌘／Ctrl + S） … 保存が終わると、画面下に「このファイルを送ってください」という案内が出ます。見逃したときのための念押しです
  • 📋 指摘をコピー（⌘／Ctrl + Shift + C） … 全コメントを文章に整えてコピーします。AIに貼って「反映して」と頼めば、そのまま直させられます。 完了した指摘は「対応済み・修正不要」と明記されるので、直した箇所を蒸し返しません
保存する前にタブを閉じてしまっても大丈夫。同じファイルを開き直すと、 「前回の未保存コメントを復元しますか？」と聞いてくれます。
